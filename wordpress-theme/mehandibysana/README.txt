Turnkey editorial WooCommerce theme for Mehandi by Sana (Srinagar, Kashmir).
Features zero-build-step assets, native WooCommerce Cart/Checkout integration,
Wildcard Indian PIN Code shipping & COD engine, interactive 48-hour Stain Oxidation Guide,
Bridal Bookings CPT, and HPOS-compatible Courier Dispatch + Offline Payment Admin Metabox.

== Installation ==
1. In WordPress Admin, navigate to Appearance -> Themes -> Add New -> Upload Theme.
2. Select `mehandibysana-theme.zip` and click Install Now, then Activate.
3. Ensure the free `WooCommerce` plugin is installed and activated.
4. Set Currency to Indian Rupee (INR) in WooCommerce -> Settings -> General.
5. Under Settings -> Permalinks, select "Post name" and click Save Changes.
6. Visit the "Mehandi Admin" top-level menu in WordPress Admin to verify all brand pages
   (Services, Gallery, About, Contact, Track Order, Terms, Privacy) are active and customize
   Wildcard PIN Shipping Rules, contact email/phone, or Bridal Booking inquiries.

== Order Dispatch, Offline Payment & Courier Workflow ==
* Open any order under WooCommerce -> Orders.
* On the right sidebar box "Mehandi by Sana — Order Dispatch, Courier & Offline Payment":
  - Pick Fulfillment Stage (Received / Preparing / Dispatched / Delivered).
  - Select a Courier Preset (including "Srinagar Local Rider / Hand Delivery", Delhivery, India Post) or type a custom name.
  - Enter optional AWB Tracking Number, URL, and customer dispatch note.
  - Check "Payment Received Offline / Cash Collected" and/or "Mark WooCommerce Order Completed".
  - Check "Send Shipping / Dispatch Email to Customer" to immediately send a branded HTML dispatch email with a one-click live `/track-order/` link.
